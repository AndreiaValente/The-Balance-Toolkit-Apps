# The Balance Toolkit

Receives Wii Balance Board center-of-pressure data from The Balance Toolkit desktop application and moves a GameObject within a parent plane.

The package installs TCP support only. Open **Balance Toolkit Demo > Setup** to add the optional samples:

- **TCP Example** creates a ready-made scene via Balance Toolkit Demo > Create TCP Example Scene.
- **LSL Integration** adds the LSL controller and enables the LSL option in the monitor window. Setup installs the required LSL4Unity compatibility build first.
- **Demo**: one click on **Add the demo scene** installs any missing dependencies (URP, Cinemachine, Timeline, Input System), imports the Demo sample and generates a playable scene with the board model, the Balu character and a connection status panel. Requires Unity 6.6. The scene can also be regenerated later from Balance Toolkit Demo > Create Demo Scene.

Full documentation: https://github.com/AndreiaValente/The-Balance-Toolkit-Apps/tree/main/unity
